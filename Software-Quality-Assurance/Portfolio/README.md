# Software Quality Assurance Portfolio

This repository contains my Software Quality Assurance portfolio, showcasing my understanding and practical application of software testing principles.

It includes testing documentation, test case design, bug reporting, and user experience evaluation from projects and testing activities.

My goal is to ensure software quality by identifying potential issues, validating application functionality, and documenting testing results systematically.

---

## 🧪 Testing Skills

| Area | Description |
|---|---|
| Manual Testing | Performing manual tests to verify application functionality |
| Functional Testing | Validating whether features work according to requirements |
| Black Box Testing | Testing application behavior without examining internal code |
| Boundary Value Analysis | Testing input values around specified boundaries |
| Negative Testing | Verifying how applications handle invalid inputs and unexpected conditions |
| API Testing | Validating REST API responses and data |
| Bug Reporting | Documenting defects with clear reproduction steps and evidence |
| UX Evaluation | Evaluating user experience using standardized questionnaires |

## 📁 Portfolio Projects

### 1. User Experience Questionnaire (UEQ) Evaluation

**Objective:** Evaluate user experience through the User Experience Questionnaire (UEQ) framework and analyze the results against benchmark data.

**Activities:**
- Analyzed UEQ questionnaire results.
- Calculated mean scores and variance across six UX dimensions.
- Compared the results against UEQ benchmark classifications.
- Created visualizations to present the evaluation results.
- Interpreted the results to identify user experience strengths and weaknesses.

**Documentation:**
- UEQ evaluation results
- Benchmark comparison
- Mean and variance analysis
- Visualization charts

[View UEQ Evaluation](./UEQ-Evaluation/)
